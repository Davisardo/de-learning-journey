# YouTube ELT

Project ini merupakan bagian dari proses belajar **Data Engineering** dengan membangun data pipeline secara end-to-end menggunakan data dari **YouTube Data API v3**.

## Tujuan Project

Project ini akan digunakan untuk mempelajari proses:

* Extract data dari YouTube menggunakan API
* Menggunakan Python untuk berinteraksi dengan API
* Load data ke PostgreSQL sebagai data warehouse
* Transform data menggunakan pendekatan ELT
* Melakukan data quality testing
* Menggunakan Docker untuk containerization
* Menggunakan Apache Airflow untuk workflow orchestration
* Melakukan unit, integration, dan end-to-end testing
* Menerapkan CI/CD menggunakan GitHub Actions

## Tools
